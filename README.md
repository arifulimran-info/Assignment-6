# FitLog

FitLog is a dark, no-nonsense workout library and daily training planner built with Next.js.

## Description

FitLog allows users to browse workouts, view detailed exercise information, add workouts to today's plan, save workouts for later, and track completed exercises.

**Live site:** https://fitlog-a6-nu-wine.vercel.app  · **Repo:** https://github.com/arifulimran-info/Assignment-6.git

## Technologies

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 3
- lucide-react (icons)
- Oswald + Inter (next/font)

## Features

- Browse workout library
- Search workouts by name, muscle group, or equipment
- Sort workouts by duration, calories, and rating
- View detailed workout information
- Add workouts to today's plan
- Save workouts for later
- Mark workouts as completed
- Remove workouts from the plan
- LocalStorage persistence
- Responsive design for mobile, tablet, and desktop
- Custom 404 page
- Loading UI
- Toast notifications
